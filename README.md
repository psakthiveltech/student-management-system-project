# Student Management System

## Project Overview

This is a full-stack web application developed to manage student information

## Technology Used In This Project

**Frontend**
 - React.js
 - Material UI
 - Axios

 **Backed**
- Java
- Spring Boot
- REST API

**Database**
- MySql

**Tools**
- Intellig Id
- Vs code
- Postman

## Main Features
- Create Students
- Update Students
- Delete Students
- View Students
- Search Students By ID

## How the Application Works

The user interacts with the React frontend.

React sends the request to the Spring Boot (backend) using Axios.

Spring Boot processes the request and communicates with the MySql database

The response is then sent back to react 

The React will show the result for user request
